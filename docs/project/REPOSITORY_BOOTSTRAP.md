## Current Boundary

This bootstrap does not lock the programming language, UI toolkit, package/namespace, Gradle structure, OCR runtime, AI runtime/model, or dependency versions. Those decisions require validation against the actual Google AI Studio-generated Android project.

## MVP Constraints

SnapData remains offline-first. A mandatory backend, REST API, or cloud database is not part of the MVP architecture.

## Next Phase

Introduce the validated Android project foundation, then implement the processing pipeline incrementally within these architectural boundaries.
